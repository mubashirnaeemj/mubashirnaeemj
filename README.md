## Selected Projects

### [AI-Based Ulcer Classification System](https://github.com/mubashirnaeemj/densenet121-ulcer-classifier) (Final Year Project, graded A)

8-class GI endoscopy image classifier built on a fine-tuned DenseNet121 (two-phase training), reaching **92.98% test accuracy** (macro F1 0.929). Wrapped in a Flask + MySQL web app with doctor and admin roles, Grad-CAM heatmaps, confidence-based rejection of unclear images, and PDF reports emailed to patients through an n8n webhook.

`TensorFlow` `Keras` `DenseNet121` `Flask` `MySQL` `SQLAlchemy` `Grad-CAM` `n8n`
